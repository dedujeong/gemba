The Story touches permissions: the shop owner sees the cost of each service and the mechanic must not.

PASS if the drafted Story's acceptance criteria include, besides the owner seeing the cost, a criterion for the rule that protects it: the mechanic does not see the cost. Each criterion states a result that can be checked as true or false by an automated test (a visible or absent cost), not a vague quality.
FAIL if there is no criterion for the mechanic not seeing the cost, or if a criterion is vague or subjective and cannot be checked automatically.
