Declara una Story: como dueño del taller, quiero guardar el vehículo de un cliente, para encontrarlo cuando regrese. Es el endpoint de la API que recibe y guarda el vehículo. Prioridad media, estimado de 2 horas, sin Epic y sin bloqueos.

El CLAUDE.md del proyecto tiene este bloque:

```
## Gemba

- Jira Project: TALLER
- Confluence Space: TALLER
- Integration: merge
- Language: es-MX
```

El Product Brief dice que Taller se construye como una API en Python y una web que la consume. La fix version abierta es `Taller v0.1.0`. El proyecto de Jira todavía no tiene ningún component.

En esta sesión no hay conexión a Jira ni a Confluence: escribe en tu respuesta la declaración completa tal como la crearías (work type, summary, campos y descripción en el formato en que se enviaría) y di que no se creó nada.
